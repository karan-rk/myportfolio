System objective

Make the portfolio conversational without making unsupported claims.

The assistant separates editable verified content from question handling and answer presentation, allowing portfolio facts to be updated centrally while the interaction remains natural.

Request / Data Flow

Question to concise recruiter answer

The browser normalizes a question, routes intent, retrieves structured portfolio facts, checks confidence, and renders the answer with follow-up context.

Engineering Decisions

Content is separate from application logic

Verified experience, project, skill, architecture, and resume facts live in one editable structured file rather than being scattered across answer templates.

Reliability & Failure Handling

Useful even when general AI is offline

Deterministic routing, focused retrieval, request validation, confidence checks, and deliberate abstention keep core portfolio questions dependable.

Tradeoffs

Trust before open-ended breadth

The assistant favors grounded portfolio answers over broad general knowledge, which limits scope but prevents unsupported candidate claims.

Future Improvements

Faster and more observable retrieval

Add semantic retrieval benchmarks, cached backend warm-up, richer evaluation datasets, and production latency monitoring.
