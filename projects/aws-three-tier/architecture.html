Architecture meaning

A resilient three-tier web application with a warm standby region.

The application separates the web, application, and database layers so each tier can scale and fail independently. A smaller secondary-region environment remains ready to take production traffic if the primary region becomes unavailable.

User→Route 53→CloudFront + WAF→Web tier→App tier→RDS

Why this design

Availability

Multiple Availability Zones prevent one data-center failure from stopping the application.

Security

Only load balancers are public; application and database resources remain in private subnets.

Disaster recovery

Route 53 can redirect users to the warm standby region while cross-region backups and replicas protect data.

01 / Normal operation

How the full warm-standby architecture works

  1. Route 53 resolves the application domain and sends normal production traffic toward the primary region.
  2. CloudFront serves cached content near users, while AWS WAF filters malicious requests before they reach the application.
  3. The public load balancer distributes traffic across web servers in separate Availability Zones.
  4. Web servers call the private application tier, which contains the business logic and can scale independently.
  5. The application tier reads and writes through Amazon RDS. A secondary database instance improves availability inside the region.
  6. Backups and cross-region replication prepare the secondary region with the data needed for disaster recovery.

02 / Regional failure

What happens during failover

  1. Health checks detect that the primary-region endpoint is no longer healthy.
  2. Route 53 changes DNS routing from the active primary endpoint to the secondary-region load balancer.
  3. The warm standby environment scales up to handle production traffic instead of being provisioned from zero.
  4. The secondary region serves requests using replicated or restored data while the primary region is repaired.
  5. After recovery and validation, traffic can be deliberately failed back to the original primary region.
