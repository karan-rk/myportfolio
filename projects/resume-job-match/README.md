# RoleFit

An upload-first explainable resume analyzer. PDF extraction uses the local portfolio service, and analysis runs automatically in the browser.

- Resume structure
- Technical skills breadth
- Measurable impact evidence
- Action-oriented writing
- Production-readiness evidence
- Bullet-level evidence quality
- Target-role readiness for four engineering and data roles
- ATS text-parsability checks
- Section-level scoring
- Evidence-safe bullet rewrite suggestions
- Before-and-after resume comparison

Open `index.html` through the portfolio server, choose a target role, and upload a PDF resume. Optionally upload a revised PDF to compare improvements.
