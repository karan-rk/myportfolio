System objective

Explain what to improve without inventing candidate evidence.

RoleFit separates PDF extraction, deterministic analysis, role-specific scoring, and evidence-safe recommendations so users can understand every result.

Architecture diagram

UploadAccept an original or revised PDF resume.
ExtractParse text through the portfolio backend.
AnalyzeInspect sections, skills, impact, and ATS readability.
RecommendGenerate prioritized evidence-safe improvements.
CompareMeasure changes between original and revised resumes.

Request / Data Flow

Resume to prioritized improvements

An uploaded PDF is parsed by the backend, evaluated against a selected role profile, and returned as inspectable recommendations and comparisons.

Engineering Decisions

Deterministic recommendations

Scoring rules and rewrite constraints remain inspectable, allowing suggestions to improve clarity while preserving facts already present in the resume.

Reliability & Failure Handling

Reject unreadable inputs clearly

File validation, extraction checks, and evidence constraints prevent empty reports and unsupported rewrite claims.

Tradeoffs

Explainability over generative flexibility

Deterministic analysis is easier to trust and debug, but less expressive than a fully generative career coach.

Future Improvements

Broaden formats and evaluation

Add DOCX parsing, saved reports, role-specific evaluation datasets, and evidence-constrained LLM assistance.
